# Renovación del Código de la Notificación Sanitaria Obligatoria de Productos Cosméticos

|  |  |  |
| --- | --- | --- |
|  | | |
| **Descripción:** | | |
| Para el ingreso de solicitudes de Renovación de la Notificación Sanitaria Obligatoria de productos sujetos a vigilancia y control sanitario, que durante su período de vigencia no hubieren sufrido cambios o modificaciones en su uso, que no hayan registrado problemas de calidad, seguridad y eficacia; se realizará a través de la VUE, de acuerdo a lo descrito en el Instructivo.   Esta solicitud deberá ser presentada dentro de los (90) días a la fecha de vencimiento de la Notificación Sanitaria Obligatoria, en caso de presentarse la solicitud de renovación luego del período de vigencia de la Notificación Sanitaria Obligatoria, esta será cancelada automáticamente por el sistema y el usuario deberá ingresar una nueva solicitud de Notificación Sanitaria Obligatoria.  **NOTA:** De encontrarse cambios realizados al producto sujeto a renovación del código de NSO, la solicitud de Renovación será cancelada y deberá notificar previamente todos los cambios efectuados y una vez aceptados estos, ingresar una nueva solicitud de renovación. | | |
| **Requisitos:** | | |
| 1. Solicitud a través de la VUE.   *Para mayor información consulte la Resolución 1333 de la CAN.* | | |
