# Requisitos autorización para importación de productos cosméticos e Higiénicos sin valor comercial con fines de estudio de mercado

|  |  |  |
| --- | --- | --- |
|  | | |
| **Requisitos:** | | |
| ***Productos Cosméticos:***   - Solicitud de autorización dirigida a la Dirección Ejecutiva de Arcsa, donde se justifique del motivo de la importación detallando: uso, cantidad y número de lote, mismos que deben ser congruentes con la actividad registrada por el solicitante.   ***Productos Higiénicos:***   - Solicitud de autorización dirigida a la Dirección Ejecutiva de Arcsa, donde se justifique el motivo de la importación detallando nombre e información técnica del producto objeto de la importación. | | |
| **Costo:** | | |
| Revisa el listado de tasas de servicios [aquí](http://www.controlsanitario.gob.ec/wp-content/uploads/downloads/2016/01/Tasas-servicios-Arcsa-2016.pdf) | | |
| **Tiempo Estimado de Entrega:** | | |
| 5 días laborables. | | |
