# Modificación de Registro Sanitario de Plaguicidas de uso doméstico, industrial y en salud pública (Fabricación Nacional y Extranjera)

|  |  |  |
| --- | --- | --- |
|  | | |
| **Requisitos Plaguicidas:** | | |
| 1. **Cambio de nombre del producto**     1. Autorización del Titular del producto,    2. Proyecto de etiquetas,    3. CLV para el caso de productos extranjeros.      2. **Cambio del nombre o razón social del titular del Registro Sanitario, para lo cual debe adjuntar:**    1. Autorización del Titular del producto,    2. RUC,    3. Registro mercantil,    4. Proyecto de etiquetas.      3. **Cambio del nombre o razón social del fabricante, para lo cual debe adjuntar:**    1. Autorización del Titular del producto,    2. RUC,    3. Registro mercantil,    4. Proyecto de etiquetas.      4. **Cambio, aumento o disminución de las formas de presentación ya registradas, si el material de envase es diferente al que fue registrado y no altera la estabilidad del producto terminado, debe adjuntar**:    1. Estudio de estabilidad actualizado,    2. Proyecto de etiqueta,    3. Especificaciones del material de envase.     **Para el caso de aumento o disminución de las formas de presentación debe presentar:**   1. Proyecto de etiquetas.      5. **Cambio o inclusión de marca, para lo cual debe adjuntar:**    1. Autorización del Titular de producto,    2. Proyecto de etiqueta.      6. **Cambio o Adición de un uso previsto del producto terminado, siempre y cuando su formulación no se haya modificado, se deberá adjuntar:**    1. Estudio de eficacia,    2. Proyecto de etiqueta. 7. **Cambio de la Vida útil del plaguicida, siempre que no se cambie las especificaciones del producto terminado, se deberá adjuntar:**    1. Estudios de estabilidad,    2. Proyecto de etiqueta.      8. **Cambio de la naturaleza del envase siempre y cuando no cambie la vida útil del producto, se deberá adjuntar:**    1. Estudio de estabilidad,    2. Especificaciones del material de envase.      9. **Cambio aumento o disminución de los excipientes de la formulación, siempre que no cambien las especificaciones iniciales con las cuales fue registrado el plaguicida, se deberá adjuntar:**    1. Estudios de estabilidad,    2. Especificaciones del producto terminado.      10. **Cambio del país de importación cuando no cambie el país de fabricación:**     1. No se requiere adjuntar requisitos únicamente la notificación del cambio.      11. **Cambio de categoría toxicológica, siempre y cuando no modifique la modalidad de venta se deberá adjuntar:**     1. Informe toxicológico según criterios de OMS,     2. Proyecto de etiqueta.   *Para mayor información revise el instructivo  [(descargue aquí)](https://www.controlsanitario.gob.ec/wp-content/uploads/downloads/2016/12/IE-D.1.1-PL-01_Requisitos_para_la_inscripci%C2%A2n_reinscripci%C2%A2n_y_Modif_del_Registro_sanitario_plaguicidas_uso_domC%CC%A7stico.pdf)* | | |
