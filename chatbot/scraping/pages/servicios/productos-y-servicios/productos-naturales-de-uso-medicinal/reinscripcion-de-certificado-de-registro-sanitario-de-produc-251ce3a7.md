# Reinscripción de Certificado de Registro Sanitario de Productos Naturales de uso medicinal (Fabricación Nacional y Extranjera)

|  |  |  |
| --- | --- | --- |
|  | | |
| **Descripción:** | | |
| A través de análisis documental se verifica que el registro sanitario / Notificación Sanitaria Obligatoria se actualizó una vez concluido su período de vigencia, y que el producto conserva todas las características aprobadas durante la inscripción. | | |
| **Requisitos:** | | |
| La Solicitud de Reinscripción del Registro Sanitario se realizará vía electrónica a la Agencia Nacional de Regulación, Control y Vigilancia Sanitaria, a través de la Ventanilla Única Ecuatoriana (VUE) del Portal Web ECUAPASS.   *Para mayor información revise el instructivo.[(DESCARGA AQUÍ)](https://www.controlsanitario.gob.ec/wp-content/uploads/downloads/2018/03/IE-D.1.1-PN-01_V3.0_REQUISITOS-INSCRIPCION_REINSCRIPCION_MOD-RS_PROD-NATURALES.pdf)* | | |
