# Inscripción de Registro Sanitario de Medicamentos Biológicos  (Fabricación Nacional)

|  |  |  |
| --- | --- | --- |
|  | | |
| **Descripción:** | | |
| Para obtener el registro sanitario por primera vez de medicamentos biológicos, de producción nacional, el fabricante o representante legal ingresará a través de la Ventanilla Única Ecuatoriana  (VUE) una solicitud individual para cada forma farmacéutica y concentración del o de los principios activos.Se considera Medicamentos biológicos a: Vacunas, hemoderivados procesados y afines homólogos (como albumina, factores de coagulación e inmunoglobulinas) y heterólogos (como toxinas y sueros hiperinmunes), Medicamentos biotecnológicos innovadores o biosimilares y Otros biológicos como Alérgenos de origen biológico; Sueros inmunes. | | |
| **Requisitos:** | | |
| 1. Solicitud ingresada por Ventanilla Única Ecuatoriana (VUE). 2. Datos para la emisión de la factura. 3. Fórmula maestra o de producción incluyendo el tamaño de cada lote. 4. Descripción de materiales de partida de origen biológico. 5. Interpretación del Código de Lote. 6. Descripción del proceso de fabricación del medicamento biológico. 7. Información detallada de las especificaciones de calidad. 8. Certificado de análisis de los principios activos, sustancias auxiliares, adyuvantes, preservantes, solventes 9. Presentación de formato de etiquetas de los envases primario y secundario 10. Informe de estudios preclínicos y estudios clínicos 11. Plan de farmacovigilancia y gestión de riesgos de acuerdo a la normativa legal vigente en el país. 12. Estudios de estabilidad natural en tiempo real en zona IV y estudios de estabilidad acelerada. 13. Sistema envase cierre.   *Para mayor información revise el instructivo* | | |
