# Certificado de Garantía de Lote

|  |  |  |
| --- | --- | --- |
|  | | |
| **Descripción:** | | |
| A través de análisis documental se verifica que los alimentos procesados que van a ser exportados cumplen parámetros bromatológicos y microbiológicos, además se garantiza que estos sean aptos para el uso y consumo humano. | | |
| **Requisitos:** | | |
| 1. 1. Ingresar la solicitud por Ventanilla Única Ecuatoriana (VUE).    2. Declarar la Norma Técnica INEN o la Norma Internacional bajo la cual se elaboró el producto.    3. Especificar el Tamaño del Lote. Incluir el número del Registro Sanitario /Notificación Sanitaria vigente (Si es del INH se solicitará debe adjuntar el RS) | | |

|  | | |
