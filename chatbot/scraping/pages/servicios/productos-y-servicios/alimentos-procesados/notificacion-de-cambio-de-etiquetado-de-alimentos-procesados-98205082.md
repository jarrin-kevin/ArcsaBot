# Notificación de Cambio de Etiquetado de Alimentos Procesados

|  |  |  |
| --- | --- | --- |
|  | | |
| **Descripción:** | | |
| A través de análisis técnico documental se verifica que los fabricantes y distribuidores de alimentos procesados cumplan con lo dispuesto en el reglamento sanitario de etiquetado de alimentos procesados para el consumo humano. | | |
| **Requisitos:** | | |
| 1. Contar con los análisis bromatológicos de su producto realizados en un laboratorio acreditado por el Servicio de Acreditación Ecuatoriano  (SAE) 2. Para calcular los datos de su producto puede ingresar en el **[Simulador](http://permisosfuncionamiento.controlsanitario.gob.ec/publico/calculadora_etiquetado/)** | | |
