# Requisitos para el registro de compañías elaboradoras, importadoras y comercializadoras al por mayor de productos de tabaco

|  |  |  |
| --- | --- | --- |
| **Descripción:** | | |
| Para el registro de compañías elaboradoras, importadoras y comercializadoras al por mayor de productos de tabaco, se deberá presentar la siguiente documentación: | | |
|  | | |
| 1. Copia del Registro Único de Contribuyentes (RUC). 2. Copias notariadas de los documentos de constitución de la sociedad o empresa. 3. Oficio dirigido a la Agencia Nacional de Regulación, Control y Vigilancia Sanitaria – ARCSA, que contenga la siguiente información:     - Nombre de la compañía o  de la Persona Natural.    - Número de RUC    - Número de Cédula de Identidad del Representante legal o,  en el caso de apoderados generales o representantes legales extranjeros, la visa correspondiente (categoría 9-IV para apoderados generales o categoría 12-VI para representantes legales con residencia temporal).    - Dirección de la empresa, en la que conste: Provincia, Cantón, Ciudad    - Números telefónicos de contacto    - Correo electrónico    - Página web (cuando aplique).    - Direcciones de redes sociales (cuando aplique). 4. Informe técnico completo y claro, mediante el cual las compañías elaboradoras, importadoras y comercializadoras al por mayor declaren:    - El tipo de producto de tabaco.    - Las marcas que elaboran, importan o comercializan.    - El número de unidades por envase individual destinado a la venta al público.    - La información correspondiente a ingredientes, componentes, aditivos y demás sustancias utilizadas en su fabricación. 5. Copias de los informes de estudios o pruebas realizadas, así como la identificación del laboratorio donde fueron efectuadas. | | |
| Obtención del permiso de funcionamiento. Una vez registrada la empresa como compañía elaboradora, importadora o comercializadora al por mayor de productos de tabaco, deberá gestionar la obtención del permiso de funcionamiento a través del Sistema Automatizado de Permisos de Funcionamiento.  **Procedimiento para la obtención del permiso de funcionamiento [Click Aquí](https://permisosfuncionamiento.controlsanitario.gob.ec/)** | | |
