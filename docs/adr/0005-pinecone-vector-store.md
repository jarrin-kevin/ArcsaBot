# Pinecone over Vertex AI Vector Search

ADR 0002 picked Vertex AI Vector Search over Pinecone to stay on a single Google vendor. That reasoning no longer holds: the project's GCP billing account was disabled for cost, leaving Vertex AI Vector Search inoperative (403 `BILLING_DISABLED`) with no code change able to fix it. We migrated to Pinecone's free Starter plan instead of re-enabling GCP billing. The corpus is small (~4600 vectors of 768 dimensions), far under Pinecone Starter's 2GB storage and 2M writes/month limits, so the free tier is not a temporary stopgap but a durable fit for this project's scale. Embeddings still come from Gemini (`gemini-embedding-001`, unchanged) — only the storage/search backend moved. Pinecone also drops the GCP-specific staging bucket, service account, and asynchronous batch-update job that Vertex AI Vector Search required: `upsert()`/`query()` are direct, synchronous API calls, which simplified `chatbot/vector_ingest.py` considerably as a side benefit.
